Android Adware Detection

Machine Learning Model for Android Security

A machine learning project focused on detecting Android adware by analyzing application permissions and behavioral features. Multiple machine learning approaches were evaluated, with LightGBM producing strong classification performance across the project datasets.

The Problem

Android adware can create unwanted advertising behavior, privacy concerns, and poor user experiences.

The objective of this project was to investigate whether machine learning could identify adware applications using extracted application features and permissions.

The Data

Two datasets were evaluated in this project.

Dataset 1

171,151 applications — 147,443 adware, 23,708 benign. 441 columns: 440 binary permission/features and 1 target label.

Dataset 2

2,000 applications — 500 adware, 1,500 benign.

Model Development

The project evaluated multiple classification algorithms before focusing on LightGBM for the final analysis. The workflow included data preparation, model training, hold-out evaluation, and 5-fold cross-validation.
